💳 Loan Default Prediction System

🚀 A Machine Learning-powered system that predicts whether a loan applicant is likely to default or not based on financial and behavioral features.

---



---

## 🧠 Problem Statement

Loan default is a major risk in banking and fintech systems.

This project aims to:
- Predict loan default probability
- Identify high-risk applicants
- Assist in better credit decision-making

---

## ⚙️ Tech Stack

- Python 🐍
- XGBoost 🌲
- Pandas 📊
- Scikit-learn 🤖
- Streamlit 🎨 (UI)
  

---
